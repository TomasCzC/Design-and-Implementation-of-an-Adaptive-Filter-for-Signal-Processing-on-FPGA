This is not a real ELF binary.

A valid MicroBlaze ELF file must be produced by the MicroBlaze GCC toolchain and linker.
It cannot be written manually as a text file.

The intended firmware source is located in:
  src/main.c
  src/platform_config.h
  src/udp_protocol.h
  src/filter_regs.h

Build requirements:
  - working mb-gcc.exe
  - generated standalone MicroBlaze BSP
  - libxil.a
  - liblwip220.a
  - lscript.ld
  - xparameters.h

The current Windows installation blocks mb-gcc.exe with:
  "Přístup byl odepřen."

Therefore the real ELF is intentionally not included.
